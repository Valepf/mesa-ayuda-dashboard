# Mesa de Ayuda con IA

Panel de seguimiento de tickets desarrollado con Python y Streamlit,
integrado con Google Sheets y un flujo de automatización en n8n.

## ¿Qué permite hacer?

- Consultar tickets y filtrar la información.
- Visualizar prioridades, estados y tiempos de resolución.
- Explorar el panel con datos ficticios de demostración.
- Consultar tickets de Google Sheets mediante autenticación.

## Flujo de trabajo

Formulario → clasificación con IA en n8n → Google Sheets → panel Streamlit.

## Tecnologías

Python · Streamlit · Pandas · Google Sheets API · OAuth 2.0 · n8n

## Código e instrucciones

El proyecto se encuentra en la carpeta [mesa_dashboard](./mesa_dashboard).

Consultá la [guía de instalación](./mesa_dashboard/README.md).

El repositorio incluye datos ficticios. Las credenciales y los tokens
de acceso se configuran localmente y no se incluyen.
